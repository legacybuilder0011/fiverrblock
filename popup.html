Hide real IP / ISP / ASN (proxy)

Your IP / ISP / ASN / country come from the TCP connection, not JavaScript. Route Chrome through a proxy to change them. The proxy is tested BEFORE it is applied, so a bad entry will not lock you out of the internet.

First-time setup guide — how do I get a proxy?
  1. Use Tor Browser (free, easiest)
    • Download from torproject.org and run it.
    • While Tor Browser is open pick the "Tor Browser" preset above, or set SOCKS5 127.0.0.1:9150.
    • Click Connect & test.
  2. Use a paid VPN with a SOCKS5 endpoint
    • Mullvad: 10.64.0.1:1080 while the Mullvad app is connected (WireGuard).
    • ProtonVPN, IVPN, AirVPN: check the provider's dashboard for the SOCKS5 host / port.
  3. Run your own SSH tunnel
    • Command: ssh -D 1080 -N user@yourserver
    • Then set SOCKS5 127.0.0.1:1080.
  4. If it says "Proxy unreachable"
    • The proxy software is not actually running (most common cause). Launch Tor Browser / your VPN, then retry.
    • Wrong port — Tor Browser is 9150, Tor daemon is 9050.
    • You are stuck with "No internet"? Click Disconnect or turn the master switch off. The extension also auto-disconnects on failed tests.

This extension does NOT ship a built-in proxy because bundling a free proxy would just be lying about where your traffic goes. Bring your own trusted one.
