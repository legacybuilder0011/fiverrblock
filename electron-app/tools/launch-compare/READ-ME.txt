The check observes the app launch and runs temporary blank profiles. It does not modify saved profiles or their engine/proxy settings. It retains only known startup options for the comparisons, replaces destinations with an unused localhost proxy, and opens no saved websites. It never loads user extensions. Raw command lines and option values stay in memory and are not included in the report. The report contains switch names, process/window counts, timings, and filtered engine errors. Only diagnostic-created processes and temporary files are cleaned up. The .cmd launcher uses a process-scoped PowerShell execution policy.
