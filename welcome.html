Privacy Shield is installed.

From this second on, every website you open is being lied to about who you are. Here is exactly what that means and how to use it.

1. What is already happening, automatically

You do not need to click anything. The moment a website loads (including its iframes, ads, and trackers), Privacy Shield rewrites the answers the page gets from Chrome so the site cannot identify your specific device:

  • Browser type & OS (User-Agent, platform, vendor, sec-ch-ua)
  • Screen resolution, color depth, pixel ratio
  • Installed fonts & plugins (returns empty)
  • Time zone — sites see UTC (or your chosen zone) only
  • CPU cores & RAM (hardwareConcurrency, deviceMemory)
  • GPU renderer (WEBGL_debug_renderer_info blocked)
  • Canvas fingerprint — noise injected into toDataURL / getImageData
  • AudioContext fingerprint — noise in getFloatFrequencyData
  • Battery API (always returns "charging, 100%")
  • Geolocation — returns coordinates you pick in the popup
  • Cookies — blocked at JS & HTTP level, purged in background
  • Network trackers — GA, GTM, FingerprintJS, Hotjar, Segment, etc. blocked
  • WebRTC IP leak guarded
  • Referer, Client-Hints, X-Client-Data stripped from every request

2. The one thing that needs YOUR action: IP / ISP / ASN

Websites don't need JavaScript to see your IP address — it's in every TCP packet leaving your computer. Your ISP name, ASN, and country are looked up from that IP. No browser extension can rewrite IP packets. To change what they see, Chrome has to send traffic through a proxy.

Privacy Shield has a built-in safe proxy client:

  1. Download and install Tor Browser.
  2. Launch it. Wait for "Connected". Keep the window open.
  3. Click the Privacy Shield icon in your toolbar.
  4. Under "Hide real IP / ISP / ASN", choose the preset "Tor Browser (127.0.0.1:9150)".
  5. Click Connect & test.
  6. You will either see "Proxy connected. Sites will see IP: …" or an error. If it errors, the extension automatically reverts — you will NOT lose internet.

Alternatives: Mullvad / Proton / IVPN SOCKS5, your own SSH ssh -D 1080. Use whatever you trust — no proxy ships with the extension.

3. Some sites will ask you to "enable cookies" — that's normal

If a captcha, login, Brave Search, Google, or payment page asks you to "enable cookies" or "enable storage", that is proof the shield is working. You can fix it with one click — per site — without disabling everything:

  1. While on the broken site, click the Privacy Shield icon.
  2. At the top of the popup you'll see the current domain and a "Pause here" button. Click it.
  3. The tab reloads, the shield stops blocking that one site, and everything else is still protected.
  4. Come back any time and click "Resume here" to re-enable the shield for that site.

You can also turn off individual defenses (cookies, canvas, fonts, etc.) globally in the popup if a category always causes trouble.

4. Reading the toolbar badge

  • ON Shield is running, direct IP connection.
  • VPN Shield is running AND proxy is connected. This is what you want for maximum privacy.
  • OFF Master switch is off. Chrome is fully exposed.

5. What this extension still cannot change

  • TLS fingerprint (JA3 / JA4) — built from the ClientHello Chrome itself sends. Use Tor or a TLS-terminating proxy.
  • Your OS-level DNS resolver — use SOCKS5 (it does DNS inside the tunnel) or an encrypted DNS resolver.
